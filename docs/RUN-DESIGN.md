# 🏃 RunDee (รันดี) — เอกสารออกแบบแอพวิ่ง

> **"ไม่ต้องรู้อะไรเลย แค่ใส่หูฟังแล้ววิ่งตามเสียงโค้ช"**
> แอพวิ่งในตระกูล FitDee — ใช้งานได้จริงบนถนนเมืองไทย ดูดี และทันสมัยด้วยฟีเจอร์ระดับแอพชั้นนำปี 2026

เอกสารนี้สังเคราะห์จากการระดมความคิด 3 คอนเซ็ปต์อิสระ (มือใหม่+โค้ช / สายข้อมูล / เกม+โซเชียล)
ตัดสินโดยกรรมการ 3 เลนส์ และตรวจช่องโหว่โดย completeness critic — คอนเซ็ปต์ **"โค้ชวิ่งส่วนตัว"
ชนะ** แล้วนำจุดเด่นของอีกสองคอนเซ็ปต์มาต่อยอด

---

## 1. คอนเซ็ปต์หลัก

**ปัญหาจริงของคนอยากวิ่ง:** ไม่รู้จะเริ่มยังไง วิ่งแล้วเหนื่อยเกิน/เจ็บ แล้วก็เลิก
**คำตอบของ RunDee:** แอพทำหน้าที่เป็น **โค้ชในหูฟัง** ที่ตัดสินใจแทนทุกอย่าง —
วันนี้วิ่งกี่นาที เดินกี่นาที พรุ่งนี้ควรพักไหม — ผู้ใช้มีหน้าที่เดียวคือกดปุ่มแล้วออกไปวิ่ง

### Core Loop (วงจรที่ทำให้กลับมาทุกวัน)
1. เปิดแอพ → เจอ **การ์ดเดียว** "เซสชั่นวันนี้" + ปุ่มใหญ่ปุ่มเดียว
2. ระหว่างวิ่ง → โค้ชเสียงไทยบอกทุกจังหวะ (วิ่ง/เดิน/เหลือกี่วินาที) จอเปลี่ยนสีทั้งจอตามช่วง
3. จบวิ่ง → เช็คอิน 15 วินาที (เหนื่อยแค่ไหน + เจ็บตรงไหน)
4. แอพ**ปรับแผนทันทีพร้อมบอกเหตุผล 1 บรรทัด** → เห็นความก้าวหน้า "วิ่งต่อเนื่องได้ 3 นาทีแล้ว จาก 60 วิ"
5. เย็นก่อนวันซ้อม → แจ้งเตือนแบบมีบริบท (อากาศ/ฝุ่น/เวลาที่เคยวิ่งสำเร็จ)

### หลักการที่ไม่ยอมแลก (จากคำเตือนกรรมการ)
- **โฮมมีการ์ดเดียว / หน้าจอวิ่งมีองค์ประกอบไม่เกิน 6 ชิ้น** — ความง่ายคือตัวโปรดักต์
- **ไม่มีคำว่า "สอบตก"** — ทำไม่ครบ = แผนขยายให้เอง, หายไปนาน = Comeback Mode ถอยแผนให้โดยไม่ตำหนิ
- **ไม่มี leaderboard แข่ง pace สาธารณะ** — การเห็นตัวเองรั้งท้ายคือทริกเกอร์การเลิกที่แรงที่สุด
  (มีเฉพาะ Buddy 1:1 และ Ghost Run แข่งกับตัวเอง)
- **ทุกการปรับแผนอัตโนมัติต้องมีเหตุผล 1 บรรทัดเสมอ** — ห้ามลดความหนักเงียบ ๆ

## 2. ฟีเจอร์ทั้งหมด

### 🎧 โค้ชเสียงไทย (หัวใจของแอพ)
- เสียงโค้ชไทยธรรมชาติ เลือกบุคลิกได้ 3 แบบ: สายฮึกเหิม / สายอบอุ่น / โหมดเงียบ (บอกเฉพาะจังหวะ)
- คิวเสียงตามเหตุการณ์: นับถอยหลังก่อนสลับวิ่ง↔เดิน 10 วิ, รายงานทุก 1 กม., วอร์มอัพ/คูลดาวน์นำเสียง
- บทเรียนสั้น 20 วิ ต่อเซสชั่น (ฟอร์มการวิ่ง, การหายใจ) — ไม่พูดพร่ำตลอดทาง
- Talk Test กลางทาง: ตอบผ่านปุ่มหูฟัง → แอพยืด/หดช่วงเดินแบบเรียลไทม์
- เพลง ducking (เบาลงตอนโค้ชพูด) + **ชดเชย Bluetooth latency** (ยิงคิวล่วงหน้า + ปุ่ม calibrate หูฟัง)
- คิวเตือนดื่มน้ำทุก 15–20 นาทีเมื่ออากาศร้อน

### 📋 แผนซ้อมปรับตัวได้ (Adaptive Plan)
- แผน 0 → 5K (8–10 สัปดาห์, วิ่งสลับเดิน) พร้อม**สะพานต่อ 5K → 10K** ตั้งแต่เวอร์ชันแรก (อุดจุด retention cliff)
- ประเมินก่อนเริ่มแบบสั้น (2–3 คำถาม) + "เดินทดสอบ 6 นาที" เป็นเซสชั่นแรกที่ได้เหรียญเลย —
  เป้าหมาย: ติดตั้งถึงวิ่งครั้งแรกภายใน 3 นาที ข้อมูลละเอียดเก็บทีหลังแบบทยอย
- Adaptive Engine ปรับจาก 3 สัญญาณ: คะแนนเหนื่อย (RPE), อัตราทำสำเร็จของช่วงวิ่ง, รายงานอาการเจ็บ
- Comeback Mode: หายเกิน 7 วัน → ถอยแผน 1–2 สัปดาห์อัตโนมัติ + ข้อความไม่ตำหนิ และ**ทักก่อน**ไม่ใช่รอ
- ตั้งเป้างานวิ่งจริงในไทย (ปฏิทินงานวิ่ง/thai.run) → แผนนับถอยหลังสู่วันงาน + โหมดวันแข่ง
- **โหมดโปร (Progressive Disclosure):** ผู้ใช้ที่พัฒนาขึ้นเปิดใช้ interval workouts, pace/HR zones,
  Ghost Run แข่งสถิติตัวเอง, Race Predictor ได้ — ของลึกมีให้ แต่ไม่โผล่มากดดันมือใหม่

### 🏃 หน้าจอขณะวิ่ง (Live Run)
- **โทนเข้มเสมอ** (อ่านง่ายกลางแดด/กลางคืน + ประหยัดแบต OLED) ตัวเลขหลักใหญ่พิเศษ
- โหมดมือใหม่: จอเปลี่ยนสีทั้งจอตามช่วง (วิ่ง/เดิน) + เวลาที่เหลือ — **ไม่มี pace กดดันโดยดีฟอลต์**
  พร้อมไอคอน 🏃/🚶 กำกับเสมอ (ไม่พึ่งสีอย่างเดียว — คนตาบอดสีแยกได้)
- โหมดตัวเลข: pace / ระยะ / เวลา / โซน HR เป็นแถบสี + ชื่อโซนกำกับ ("โซน 2 · สบาย")
- แถบโครงสร้างเซสชั่นแบบบล็อก (วอร์ม→วิ่ง→เดิน→คูลดาวน์) เห็นว่าอยู่ช่วงไหน เหลือกี่ช่วง
- ปุ่มใหญ่กดได้ทั้งที่มือเปียกเหงื่อ: พัก / ขอเดินเพิ่ม / จบ (กดค้าง 2 วิ กันพลาด) + ปุ่มล็อกจอ
- Auto-pause ติดไฟแดง, สั่นเตือนเมื่อสลับช่วง, Live Activity บนจอล็อก (iOS) / ongoing notification (Android)
- สถานะ GPS แบบเรียลไทม์: สัญญาณหาย → ขึ้น "กำลังประเมินระยะจากก้าวแทน" ไม่ปล่อยตัวเลขมั่วเงียบ ๆ

### 🛡️ ความปลอดภัย (Safety Package — ครบชุดในแอพเดียว)
- **Live Tracking:** แชร์ลิงก์ตำแหน่งสดให้คนที่บ้านดูผ่านเว็บ ไม่ต้องมีแอพ
- **ปุ่ม SOS** ส่งพิกัดหาผู้ติดต่อฉุกเฉิน + **Incident Detection** (ล้ม/หยุดนิ่งผิดปกติ → ถามก่อน แล้วส่งข้อความอัตโนมัติ)
- **เฝ้าระวังฮีทสโตรกกลางทาง:** HR พุ่งสวนทาง pace ตก + อากาศร้อน → โค้ชสั่งชะลอ/หาที่ร่มทันที
- เตือน HR เกินเพดานอายุผิดปกติ (เชิงความปลอดภัย ไม่ใช่แค่เชิงซ้อม)
- โหมดวิ่งกลางคืน: จอมืด + เตือนอุปกรณ์สะท้อนแสง + แนะนำ transparency mode/หูข้างเดียวริมถนน
- ICE (In Case of Emergency): กรุ๊ปเลือด/แพ้ยา/เบอร์ฉุกเฉิน เข้าถึงได้จากจอวิ่ง
- คัดกรองความเสี่ยงหัวใจตอน onboarding (คำถามโรคประจำตัว แนว PAR-Q) — กลุ่มไม่เคยออกกำลังกาย
  มาวิ่งกลางอากาศร้อนคือกลุ่มเสี่ยงสูงสุด
- กติกา Injury Guard ทุกข้อ**ต้องผ่านรีวิวโดยนักกายภาพ/แพทย์เวชศาสตร์การกีฬา** + disclaimer ชัด ไม่วินิจฉัยเอง

### 🇹🇭 ออกแบบเพื่อนักวิ่งไทยโดยเฉพาะ
- **ชิป PM2.5/AQI บนหน้าแรก** (API Air4Thai/IQAir) — ฝุ่นแดง → เสนอสลับเป็นเซสชั่นในร่ม/ลู่วิ่ง โดยแผนไม่พัง
- **Heat Index Warning** ร้อนเกิน ~32°C → เสนอย้ายเวลา (ตี 5–7 โมง / หลัง 6 โมงเย็น) หรือลดความหนัก
- **Heat-Adjusted Pace:** "วันนี้ช้าลง 20 วิ/กม. แต่เทียบเท่าความพยายามเดิม เพราะอากาศ 34°" — กันท้อ
- พยากรณ์ฝนรายชั่วโมง → "อีก 2 ชม. ฝนตก 80% เลื่อนเป็นพรุ่งนี้เช้าไหม" (ปุ่มเลื่อนหนึ่งแตะ) + เตือนฝนฟ้าคะนองกลางเซสชั่น
- **ฐานข้อมูลสวนสาธารณะ:** ระยะต่อรอบ (สวนลุม 2.5 กม., สวนรถไฟ 3.2 กม., เบญจกิติ ฯลฯ),
  เวลาเปิด–ปิด, จุดน้ำ/ห้องน้ำ + **นับรอบอัตโนมัติ** เมื่อวิ่งวนลูปเดิม
- Route Discovery แท็กภาษาคน: ร่มเงา / ทางเรียบ / มีห้องน้ำ / ไฟสว่าง–ปลอดภัยกลางคืน
- โหมดลู่วิ่ง (Treadmill) ด้วย accelerometer + calibrate หลังวิ่ง — จำเป็นกว่าตลาดตะวันตกเพราะหนีร้อน/ฝุ่น
- เสียงโค้ช พ.ศ./ค.ศ. หน่วย กม. เป็นดีฟอลต์ (สลับไมล์/ภาษาอังกฤษได้สำหรับ expat) + แชร์ตรงเข้า LINE

### 📈 หลังวิ่ง & ความก้าวหน้า
- หน้าสรุป: แผนที่ hero เส้นทางไล่สีตาม pace → ตัวเลขหลัก 4 ช่อง → **AI Insight ภาษาคน 2–3 ประโยค**
  → กราฟ splits ราย กม. → เวลาในแต่ละโซน HR → ปุ่มแชร์
- กราฟหลักของมือใหม่คือ "นาทีวิ่งต่อเนื่องนานสุด" และ "นาทีสะสม/สัปดาห์" (ไม่ใช่ pace — ลดการกดดัน)
- Share Card 3 เทมเพลต (overlay บนรูป / แผนที่+สถิติ / minimal) สัดส่วน 9:16 + 1:1
  **privacy-by-default: ตัดหัว–ท้ายเส้นทาง 300 ม. ใกล้บ้านอัตโนมัติ**
- สตรีคแบบยืดหยุ่น: นับ "สัปดาห์ที่ซ้อมครบ" + **Streak Shield อัตโนมัติวันฝุ่น/ฝน** ("วันนี้ฝุ่นเยอะ พักได้ สตรีคไม่ขาด")
- เหรียญ milestone จับต้องได้: วิ่งต่อเนื่อง 1/5/10 นาที, 1 กม.แรก, 5K แรก (โชว์ความสำเร็จ ไม่โชว์ pace)
- จดหมายจากโค้ชรายสัปดาห์ + **Monthly Wrapped** สรุปเดือนแบบสไลด์แชร์ได้
- **Shoe Tracker:** ไมล์สะสมต่อรองเท้าแต่ละคู่ เตือนเมื่อใกล้ 500–800 กม. (ผูกกับการป้องกันบาดเจ็บ)
- Personal Records อัตโนมัติ: 1K/5K/10K เร็วสุด, ไกลสุด, วิ่งต่อเนื่องนานสุด

### 🔌 ความทนทานภาคสนาม (จุดที่แอพส่วนใหญ่พลาด — เราออกแบบตั้งแต่แรก)
- **ออฟไลน์เต็มรูปแบบ:** GPS บันทึกลงเครื่อง sync ทีหลัง, cache เสียงโค้ช/แผน/แผนที่ล่วงหน้า,
  แผนสำรองในเครื่องเมื่อ server ล่ม (หน้า Today ไม่มีวันว่าง)
- **Crash Recovery:** แอพเด้ง/แบตหมด → กลับมาเจอ dialog "พบการวิ่งค้างอยู่ 32 นาที — วิ่งต่อ / บันทึก / ทิ้ง"
- ตรวจจับ "ลืมกดจบ" (ขึ้นรถ/นั่งนิ่งนาน) + แก้ไข/ตัด GPS เพี้ยน/เปลี่ยนประเภท/ลบกิจกรรมย้อนหลังได้
- นโยบายแบตต่ำ: auto-save + ลดความถี่ GPS + ปิดจอ
- **Wizard ตั้งค่าแบตเตอรี่ต่อยี่ห้อ** (Xiaomi/Oppo/Vivo ครองตลาดไทยและชอบฆ่า background app)
  + ตรวจก่อนสตาร์ททุกครั้ง
- กันข้อมูลซ้ำ (dedup) เมื่อ sync จากนาฬิกา + มือถือ + Strava พร้อมกัน
- วิ่งข้ามเที่ยงคืนนับเป็นวันที่เริ่มวิ่ง (นักวิ่งไทยวิ่งดึกหนีร้อนเยอะ)

### 🔒 ความเป็นส่วนตัว (PDPA-first)
- Privacy Zone รอบบ้าน/ที่ทำงาน — เบลอ/ตัดเส้นทางอัตโนมัติก่อนแชร์ทุกช่องทาง
- Privacy Center: consent แยกประเภท, export ข้อมูล (GPX/TCX), ลบบัญชี/ลบข้อมูลทั้งหมดได้ในแอพ
- ข้อมูล HR = ข้อมูลสุขภาพ เก็บแบบเข้ารหัส, มี age gate สำหรับผู้เยาว์
- โซเชียลมีแค่ Buddy 1:1 + ระบบ block/report ตั้งแต่วันแรก

### 🔗 เชื่อมต่อ
- Apple Watch / Wear OS / Garmin / สายคาดอก HR (Bluetooth LE)
- Apple Health / Health Connect / Strava (ขาออก พร้อม granular consent)
- Spotify / Apple Music (ducking — ระบุชัดว่าคุมได้แค่ไหนต่อแพลตฟอร์ม ไม่สัญญาเกินจริง)
- บัญชีเดียวกับ FitDee: สตรีครวมกัน, วันพักเสนอคลาสยืดเหยียด/Strength for Runners จาก FitDee,
  cross-training นับเข้าความสม่ำเสมอ

## 3. โครงสร้างหน้าจอ

```
Bottom Nav 5 ช่อง (ปุ่มกลางนูนเด่น)
├── 🏠 วันนี้     → การ์ดเซสชั่นวันนี้ / อากาศ+ฝุ่น / สตรีค / วันพักมี state ของตัวเอง
├── 📋 แผนซ้อม   → ไทม์ไลน์แผน / Guided Runs / ปฏิทินงานวิ่ง
├── ▶️ [วิ่ง]     → Pre-run (GPS·เพลง·วอร์มอัพ) → Live Run → เช็คอิน → สรุป
├── 🗺️ เส้นทาง   → สวนใกล้ฉัน + แท็กภาษาคน / เส้นทางที่บันทึกไว้
└── 📊 สถิติ      → กราฟ / PR / รองเท้า / เหรียญ / โปรไฟล์+ตั้งค่า
```

หน้าจอที่มักถูกลืมแต่เราออกแบบด้วย: จอ Pause, จอ Error states (GPS หาย/permission ถูกปฏิเสธ),
dialog กู้เซสชั่น, หน้า Today วันพัก, จอแก้ไขกิจกรรม, ศูนย์แจ้งเตือน, จอตั้งค่าเสียงโค้ชละเอียด,
Privacy Center, Wizard แบตเตอรี่, Empty states, จอ Help/รายงานปัญหา

## 4. Design System (ต่อยอดจาก FitDee)

- ชุดสีเดียวกับ FitDee (ผ่าน colorblind-safe + contrast validation แล้ว) — น้ำเงิน `#2a78d6/#3987e5` เป็น accent หลัก
- **หน้าจอวิ่งสดบังคับโทนเข้มเสมอ** ตัวเลข ≥ 96pt สำหรับค่าหลัก
- สี semantic คงที่ทุกหน้า: เขียว = ดีกว่าเป้า/เดิน, ส้ม = ช่วงวิ่ง/หนัก — **มีไอคอน+ข้อความกำกับเสมอ**
- โซน HR: แถบสี + ชื่อโซนเป็นตัวหนังสือ ("โซน 3 · กำลังดี") ไม่พึ่งสีเดี่ยว
- Micro-interactions ที่ทำให้ "ดูแพง": haptic ทุก กม., ตัวเลข count-up ในหน้าสรุป, confetti ตอนทำ PR
- รองรับปรับขนาดฟอนต์ + TalkBack/VoiceOver

## 5. ความเสี่ยงหลัก & ทางแก้ (จากกรรมการ)

| ความเสี่ยง | ทางแก้ |
|---|---|
| เสียงโค้ชไทยดีเลย์/แข็งทื่อ = trust พังทั้งแอพ | **Prototype คิวเสียงบนหูฟัง BT จริงเป็นสิ่งแรก** ก่อน commit ดีไซน์อื่น |
| Android ไทย (Xiaomi/Oppo/Vivo) ฆ่า background | Foreground service + wizard ต่อยี่ห้อ ทดสอบตั้งแต่ sprint แรก |
| Retention cliff หลังจบแผน 5K | สะพาน 5K→10K + โหมดวิ่งเพื่อสุขภาพ ออกแบบเสร็จก่อนผู้ใช้รุ่นแรกจบคอร์ส |
| Scope creep ทำลายความง่าย | กติกาเหล็ก: โฮมการ์ดเดียว / จอวิ่งไม่เกิน 6 องค์ประกอบ ทุกฟีเจอร์ใหม่ต้องผ่าน |
| กติกาสุขภาพ/อาการเจ็บ | รีวิวโดยนักกายภาพ/แพทย์ + disclaimer ทุกจุด |
| ข้อมูลตำแหน่ง = ที่อยู่บ้าน | Privacy zone + ตัดเส้นทาง 300 ม. อัตโนมัติ + PDPA center ตั้งแต่เวอร์ชันแรก |
