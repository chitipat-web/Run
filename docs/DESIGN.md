# 🏋️ FitDee (ฟิตดี) — เอกสารออกแบบแอพออกกำลังกาย

> แอพออกกำลังกายที่ "ดูดี" และ "ใช้งานได้ครบ" — ออกแบบมาให้คนธรรมดาอยากเปิดใช้ทุกวัน
> ไม่ใช่แค่แอพจดบันทึก แต่เป็นเพื่อนคู่ซ้อมที่ช่วยวางแผน พาเล่น และให้กำลังใจ

---

## 1. คอนเซ็ปต์หลัก

**"เปิดแอพปุ๊บ รู้ทันทีว่าวันนี้ต้องทำอะไร"**

ปัญหาของแอพออกกำลังกายส่วนใหญ่คือข้อมูลเยอะเกินไปจนผู้ใช้งง หรือน้อยเกินไปจนไม่มีประโยชน์
FitDee ยึดหลัก 3 ข้อ:

1. **One-glance clarity** — หน้าแรกตอบคำถามเดียว: วันนี้เล่นอะไร นานแค่ไหน
2. **Guided, not just logged** — แอพพาเล่นทีละท่า มีตัวจับเวลา มีวิดีโอ/ภาพประกอบ ไม่ใช่แค่ให้จดเอง
3. **Momentum over perfection** — เน้น streak และความต่อเนื่อง ไม่กดดันด้วยตัวเลขที่ทำไม่ถึง

**กลุ่มเป้าหมาย:** ผู้เริ่มต้น–ระดับกลาง อายุ 18–45 ที่อยากออกกำลังกายที่บ้านหรือฟิตเนส
โดยไม่ต้องจ้างเทรนเนอร์

## 2. ฟีเจอร์ทั้งหมด (Feature Map)

### 🏠 หน้าแรก (Home)
- การ์ด "แผนวันนี้" — โปรแกรมที่ต้องเล่นวันนี้ พร้อมปุ่มเริ่มใหญ่ ๆ ปุ่มเดียว
- Streak 🔥 จำนวนวันติดต่อกัน + วงแหวนความคืบหน้ารายสัปดาห์
- สรุปวันนี้: แคลอรี่ / นาทีที่เล่น / จำนวนท่า
- Quick actions: เล่นด่วน 7 นาที, ยืดเหยียด, คาร์ดิโอ

### 💪 ออกกำลังกาย (Workout)
- **โปรแกรมสำเร็จรูป** แยกตามเป้าหมาย: ลดไขมัน / สร้างกล้าม / ฟิตหุ่น / มือใหม่ 30 วัน
- **คลังท่าออกกำลังกาย (Exercise Library)** ค้นหา + กรองตามกล้ามเนื้อ/อุปกรณ์
  แต่ละท่ามีภาพเคลื่อนไหว, คำแนะนำ, ข้อควรระวัง
- **สร้างโปรแกรมเอง (Workout Builder)** ลากท่ามาเรียง กำหนดเซ็ต/ครั้ง/เวลาพัก
- **โหมดเล่นจริง (Active Workout)**
  - แสดงท่าปัจจุบัน + ท่าถัดไป
  - ตัวจับเวลาเซ็ต + เวลาพักอัตโนมัติ (นับถอยหลังพร้อมเสียงเตือน)
  - บันทึกน้ำหนัก/ครั้งที่ทำได้ระหว่างเล่น แตะครั้งเดียวจบ
  - ปุ่มข้าม/แทนที่ท่า เมื่ออุปกรณ์ไม่ว่าง

### 📊 สถิติ (Progress)
- กราฟแท่งนาทีออกกำลังกายรายสัปดาห์
- กราฟน้ำหนักตัว + เป้าหมาย
- สถิติสูงสุด (Personal Records) ต่อท่า
- ปฏิทิน heatmap ว่าเล่นวันไหนบ้าง
- ภาพเปรียบเทียบ Before/After (เก็บในเครื่อง เป็นส่วนตัว)

### 👤 โปรไฟล์ (Profile)
- เป้าหมาย: ลดน้ำหนัก/เพิ่มกล้าม/สุขภาพ + น้ำหนักเป้าหมาย
- เหรียญรางวัล (Achievements) ปลดล็อกตามความต่อเนื่อง
- ตั้งค่าแจ้งเตือนเวลาซ้อม, หน่วย (กก./ปอนด์), ธีมมืด/สว่าง
- เชื่อมต่อ Health app (Apple Health / Google Fit)

### 🔔 ระบบเสริมที่ทำให้คนกลับมาใช้
- แจ้งเตือนอัจฉริยะ: เตือนตามเวลาที่ผู้ใช้เคยเล่นจริง ไม่ใช่เวลาสุ่ม
- ปรับแผนอัตโนมัติ: ถ้าขาดซ้อม 3 วัน แอพลดความหนักให้ ไม่ใช่ด่า
- โหมดออฟไลน์เต็มรูปแบบ — เล่นในยิมที่ไม่มีเน็ตได้

## 3. โครงสร้างหน้าจอ (Navigation)

```
Tab Bar (4 แท็บ)
├── 🏠 หน้าแรก      → แผนวันนี้ / streak / เริ่มเล่น
├── 💪 ออกกำลังกาย  → โปรแกรม / คลังท่า / สร้างเอง
│      └── ▶ โหมดเล่นจริง (เต็มจอ มีตัวจับเวลา)
├── 📊 สถิติ         → กราฟ / PR / ปฏิทิน
└── 👤 โปรไฟล์      → เป้าหมาย / เหรียญ / ตั้งค่า
```

หลักการ: **ทุกอย่างที่ใช้บ่อยต้องแตะไม่เกิน 2 ครั้ง** — เริ่มเล่นโปรแกรมวันนี้ = แตะครั้งเดียวจากหน้าแรก

## 4. Design System

### สี (ผ่านการตรวจ colorblind-safe และ contrast แล้ว)

| Role | Light | Dark |
|---|---|---|
| Accent หลัก (ปุ่ม/กราฟ) | `#2a78d6` | `#3987e5` |
| สำเร็จ/เสร็จแล้ว | `#0ca30c` | `#0ca30c` |
| Streak/พลังงาน | `#eb6834` | `#d95926` |
| พื้นหลังหน้า | `#f9f9f7` | `#0d0d0d` |
| พื้นผิวการ์ด | `#fcfcfb` | `#1a1a19` |
| ตัวอักษรหลัก | `#0b0b0b` | `#ffffff` |
| ตัวอักษรรอง | `#52514e` | `#c3c2b7` |

### ตัวอักษร
- ระบบ sans (`system-ui`) รองรับไทยดี โหลดเร็ว
- ตัวเลขใหญ่ (streak, แคลอรี่) ใช้น้ำหนัก 800 ขนาด 32–44px ให้อ่านขณะเหงื่อออกได้

### หลักการ UI
- การ์ดมุมโค้ง 16–20px, เงาบางเบา ไม่หนัก
- ปุ่มหลักสูง ≥ 52px (แตะง่ายตอนมือสั่นหลังเล่นเสร็จ)
- รองรับ Dark mode ตั้งแต่แรก (คนเล่นตอนเช้ามืด/กลางคืนเยอะ)
- ทุกกราฟมี label ตัวเลขชัดเจน ไม่พึ่งสีอย่างเดียว (colorblind-friendly)

## 5. เทคโนโลยีที่แนะนำ

| ส่วน | ตัวเลือกแนะนำ | เหตุผล |
|---|---|---|
| แอพมือถือ | **Flutter** หรือ React Native | เขียนครั้งเดียวได้ iOS + Android |
| ฐานข้อมูลในเครื่อง | SQLite / Drift | ต้องออฟไลน์ได้ 100% |
| ซิงก์ข้อมูล | Supabase / Firebase | ง่าย ราคาเริ่มฟรี |
| ข้อมูลท่าออกกำลังกาย | ชุดข้อมูลเปิด (เช่น wger) + ภาพเคลื่อนไหวของตัวเอง | เริ่มได้เร็ว |
| Health integration | HealthKit + Health Connect | ดึงก้าวเดิน/ชีพจร |

## 6. แผนพัฒนา (Roadmap)

- **MVP (เฟส 1):** หน้าแรก + คลังท่า + โหมดเล่นจริงพร้อมตัวจับเวลา + บันทึกประวัติ
- **เฟส 2:** กราฟสถิติ, streak, achievements, แจ้งเตือน
- **เฟส 3:** Workout builder, ซิงก์ cloud, Health integration
- **เฟส 4:** โซเชียล (ชวนเพื่อนแข่ง streak), AI แนะนำแผน
