# FitDee (ฟิตดี) 🏋️

แอพออกกำลังกายที่ออกแบบมาให้ **ดูดี ใช้งานครบ และอยากเปิดใช้ทุกวัน**

| ไฟล์ | คืออะไร |
|---|---|
| [`docs/DESIGN.md`](docs/DESIGN.md) | **FitDee** — เอกสารออกแบบแอพออกกำลังกายทั่วไป: คอนเซ็ปต์ ฟีเจอร์ โครงสร้างหน้าจอ ระบบสี แผนพัฒนา |
| [`mockup/index.html`](mockup/index.html) | ม็อคอัพ FitDee แบบอินเทอร์แอคทีฟ — 5 หน้าจอ |
| [`docs/RUN-DESIGN.md`](docs/RUN-DESIGN.md) | **RunDee** 🏃 — เอกสารออกแบบแอพวิ่ง: โค้ชเสียงไทย แผนปรับตัวได้ ความปลอดภัย และฟีเจอร์เพื่อนักวิ่งไทย (PM2.5, Heat Index, สวนสาธารณะ) |
| [`mockup/run.html`](mockup/run.html) | ม็อคอัพ RunDee แบบอินเทอร์แอคทีฟ — 6 หน้าจอ รวมหน้าวิ่งสดและสรุปหลังวิ่ง |

## ดูม็อคอัพ

เปิดไฟล์ `mockup/index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
รองรับทั้งธีมสว่างและธีมมืดตามการตั้งค่าเครื่อง
